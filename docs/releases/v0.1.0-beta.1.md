## Install

1. Download **RSOverlay-v0.1.0-beta.1-windows-x64.zip** below and unzip it anywhere.
2. Start SteamVR, then run `rsoverlay.exe --vr` (from a terminal, or a shortcut with `--vr` added).
3. From then on SteamVR starts RSOverlay by itself. Turn that off in SteamVR › Settings › Startup / Shutdown.
4. Turn on **Settings › Updates › Include test builds** so RSOverlay tells you when the next test build is out. It never updates itself.

Windows 10/11 x64 and SteamVR required. Settings live in `%APPDATA%\RSOverlay\`.

## Quick start in VR

- **Double-press A / X** on your wrist hand (or press the wrist's Dashboard button) to open the dashboard.
- **Trigger** clicks, **grip** grabs a panel. While grabbing: stick up/down pushes and pulls, left/right resizes.
- **Wrist › Add** opens a window or monitor in VR. Pin it on its toolbar to keep it visible when the dashboard closes.

## What's in this build

**Windows in VR**
- Mirror any monitor or single window, several at once, with a real laser mouse (click, drag, right/middle click, scroll)
- Per-window opacity, snap windows edge to edge, dock to world / head / hand
- Unpinned windows hide with the dashboard; everything steps aside while the SteamVR menu is open

**Wrist and dashboard**
- A customisable wrist "smartwatch": clock, media, batteries, layouts, and status chips for VR fps, CPU/GPU, VRAM, RAM and alerts
- 8 layout slots; your last session comes back next time

**Performance**
- PC performance card: CPU, busiest core, GPU, RAM, VRAM, plus SteamVR game fps vs refresh rate, GPU headroom and reprojection, so you can see why the game is lagging

**From your feedback**
- The laser now hits the panel you see on top (the keyboard over a window no longer "uses a different angle")
- One stick action at a time while grabbing, optional tilt with the controller
- Dedicated right / middle click bindings (bind them in SteamVR › Controller Bindings › RSOverlay)
- Pointer size, and a **Resolution** setting (High / Ultra) for sharper text on high-res headsets like the Bigscreen Beyond 2

**Also**
- VR keyboard with your Windows layout, typing sounds, VRChat chatbox mode
- Notifications (works with VRCX), media controls, volume mixer, battery alerts, night light, Discord Rich Presence (opt-in)

## Known issues

- First build: none of the new options have had much headset time yet.
- Starting `rsoverlay.exe` without `--vr` opens the desktop preview window, not VR.
